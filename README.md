# Echoes of the Ruins

A Unity 6.3 low-poly graybox stealth-exploration vertical slice. Collect three energy cores, avoid the guardian, unlock the sealed exit, and escape.

The default scene can remain empty: `RuinSceneBootstrap` constructs the playable ruins at runtime from Unity primitives and generated materials. See [PLAYTEST.md](PLAYTEST.md) for controls and the validation route.
