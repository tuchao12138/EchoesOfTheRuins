# Eight-page coursework report outline

1. **Overview and USP** — a compact third-person stealth exploration slice: shadow, echo stones and a three-core escape route.
2. **Narrative and player fantasy** — an explorer restores stolen cores while avoiding an awakened guardian.
3. **Visual direction** — moonlit blue-grey ruins, cyan runes, amber guardian/fire contrast; include concept and in-editor screenshots.
4. **Level and controls** — entry tutorial, courtyard, shadow side chamber, altar, sealed exit; WASD/mouse/Space/C/Shift/Q.
5. **Prototype evidence A: core, checkpoint and exit** — class diagram, screenshots and unique-core tests.
6. **Prototype evidence B: stealth AI** — state diagram (Patrol, Investigate, Search, Chase, Capture), sight-ray and NavMesh evidence.
7. **Local data layer and testing** — JSON save/settings/score, automated test table and full-run test recordings.
8. **Version control and reflection** — Git commits, public repository link, asset licence table, scope decisions and next steps.

Appendices: level plan, UI screenshots, test-result XML screenshots, Git log, asset sources and recording links.
