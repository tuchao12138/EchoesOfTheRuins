# Coursework requirement mapping

Source checked: `GameDevCoursework2026_Reassess_001_v1.pdf` (4 pages). Submission deadline shown in the brief: **07 August 2026, 15:00**.

## Mandatory format

- Unity 3D individual game design and development project.
- Game design report: maximum **8 pages** of body text, font size **11**.
- Appendix: up to **10 pages**.
- GitHub must be used for developed code and meaningful version-control evidence.
- The report must explain what was achieved and how, and provide the background for the video demonstration.

## Marking evidence map

| Quality and clarity | 10% | Eight-page structure, asset table, test matrix and consistent terminology prepared | Student must edit the final report for accuracy, personal reflection, formatting and academic-integrity compliance |

## Honest completion estimate

- Playable game implementation: **about 88%**.
- Visual polish for a coursework vertical slice: **about 78%**.
- Full coursework submission package: **about 68%**.

The lower submission percentage is caused by missing GitHub remote evidence, three unsigned manual Windows runs, final video and the student's final eight-page report. Automated tests and generated outlines do not replace those items.

## Required final evidence

1. Main menu and controls/settings screenshots.
2. Entrance/tutorial screenshot with player, objective and first route.
3. Guardian patrol/investigate/chase evidence with the matching HUD state.
4. Echo-stone investigation and shadow/crouch evidence.
5. `3/3` exit unlock and final score screen.
6. EditMode and PlayMode XML result screenshots.
7. GitHub branch/commit history and public repository link.
8. Asset source/licence appendix.
9. Three full Windows run records listed in `PLAYTEST.md`.

Reference repositories may be discussed as design/architecture research only. Do not copy their code, levels, screenshots or prose into the assessed submission.
